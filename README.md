# ATM Simulator (Java & MySQL)

A desktop-based ATM Simulator application developed using **Java (Swing)** and **MySQL**, designed to replicate real-world ATM operations such as user authentication, balance enquiry, deposits, withdrawals, and transaction history.

## Features
- Secure user login with PIN authentication
- Balance enquiry
- Cash deposit and withdrawal
- Mini statement / transaction history
- PIN change functionality
- MySQL-backed persistent data storage

## Tech Stack
- Java (Swing for GUI)
- MySQL (Database)
- JDBC (Database connectivity)
